GET /weather

현재 기온, 6시간 예보(기온·강수·하늘상태), 자외선, 대기질 데이터를 반환합니다.

요청

GET /weather?region_code=1147062000
region 파라미터 fallback region_code 없이 GET /weather?region=서울특별시 양천구로도 요청 가능합니다.

응답 예시

{
  "region_code": "1147062000",
  "region_name": "서울특별시 양천구",
  "baseDate": "20260603",
  "baseTime": "1800",
  "temp": 26.1,
  "tempForecast": [27, 25, 25, 24, 23],
  "rain": ["강수없음", "강수없음", "강수없음"],
  "sky": ["흐림", "흐림", "맑음"],
  "uv": 1.0,
  "o3": "0.041",
  "pm10": "13",
  "pm10Grade": "1",
  "pm25": "10",
  "pm25Grade": "1"
}

필드 설명

필드타입설명
region_codestring행정구역 코드
region_namestring지역명
baseDatestring관측 기준 날짜 (YYYYMMDD)
baseTimestring관측 기준 시각 (HHMM)

"맑음" "흐림" "비" "눈" NEW

o3string | null오존 농도 (ppm) NEW

주의사항 대기질 데이터(o3, pm10, pm25, grade)는 측정소 매핑이 안 되는 지역에서 null로 올 수 있습니다.
tempForecast, rain, sky 배열 길이는 동일하며, 보통 5~6개입니다.
GET /recommend

현재 날씨 패턴에 맞는 AI 기반 옷차림 추천 데이터를 반환합니다.

요청

GET /recommend?region_code=1147062000

응답 예시

{
  "pattern": "temp:25-29|diff:small|rain:none|pm:good|wind:calm|uv:low|pty:none",
  "top": ["반팔 티셔츠", "린넨 셔츠"],
  "bottom": ["반바지", "면바지"],
  "mask": "불필요",
  "pack": "자외선 차단제",
  "acc": ["모자", "선글라스"],
  "reason": "현재 기온 25~29도로 여름 날씨입니다. 비 소식이 없고 대기질이 좋아 가벼운 옷차림을 추천합니다."
}

필드 설명

필드타입설명
patternstring매칭된 날씨 패턴 키 (디버깅용)
topstring[]추천 상의 목록
bottomstring[]추천 하의 목록
maskstring마스크 착용 권고
packstring추가 준비물 권고
accstring[]추천 액세서리 목록
reasonstringAI 생성 추천 사유 설명
