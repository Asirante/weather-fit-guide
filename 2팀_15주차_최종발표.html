01 · Overview

프로젝트 개요

주제

전국 기상·대기질을 한눈에 + 복장·마스크 지수를 즉시 확인하는 정밀 생활 가이드

기획 의도

날씨 확인 → "뭐 입지?"까지 한 화면에서 해결

핵심 목표

요청당 서비스 비용 0원에 가까운 비용 효율 클라우드 네이티브 아키텍처 구현·증명

👉 이번 변경들로 서빙(요청) 비용을 사실상 0원으로 만들고, 추론 비용을 1회 배치로 고정했습니다.

06 · Troubleshooting

트러블슈팅 (운영 안정화)

수집 중단 진단

화면에 며칠 전 데이터 → 원인은 수집 EventBridge / Step Functions 미동작 (로그 부재로 특정) → 재가동

시간별 예보 누적 버그

지난 예보가 쌓여 시각·값 불일치 → "최신 발표분만" 조회 + TTL, 예보 base_time 규격(매시 30분) 정정

코드 품질 전수 개선

localStorage 크래시 방어 · 요청 레이스 가드 · S3 페이지네이션 · API 재시도 · 접근성 · 문서/IaC 현행화

수집 비용 최적화

1시간 일괄 → 데이터 특성별 차등 주기(예보 3시간·자외선 6시간)로 월 ₩30만 → 약 ₩15만 절감

자외선 시간 정합

자외선 API(V5) hN = 발표시각+N시간 → 예보 시각별로 정렬해 표시 · 추천 키는 현재시각 기준 산정

06 · Scalability & Extensibility

확장 가능성

본 서버리스 구조는 핵심 변경 없이 다음 방향으로 확장됩니다.

예보 지평·변수 확장

초단기예보(6시간) → 단기예보로 12시간+ 예보 및 강수확률 등 변수 확장

공간 확장 · 비용 최적화

격자/측정소 추가로 Distributed Map 그대로 수평 확장 · 예보 격자 단위 저장(중복 제거)으로 적재 비용 선형 절감

추천 고도화

패턴 차원 확대(시간대별·개인화), 사용자 피드백 학습으로 추천 정밀도 향상

분석 계층 · 운영 자동화

S3 원본 → Glue/Athena 통계·트렌드 분석 · 배포 시 CloudFront 캐시 무효화 자동화 · CI 승인 게이트로 운영 신뢰성 확장
